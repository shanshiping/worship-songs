# 敬拜选歌平台 — 功能介绍报告

**更新日期：** 2026-08-04  
**适用版本：** 当前 `main` 分支（含 2026-07 基础能力 + 2026-08 重大迭代）

---

## 一、平台定位

敬拜选歌平台面向敬拜团队，提供**曲库管理、聚会选歌记录、歌单编排、数据导入导出、团队协作与公开分享**等能力。平台采用 Next.js App Router + PostgreSQL，支持**中英双语界面**（默认英文，Cookie 持久化），并按角色控制编辑与上传权限。

## 三、原有核心功能（持续可用）

### 3.1 歌曲管理

- 上传、编辑、删除歌曲（按角色）
- 歌谱（图片/PDF）、音频、封面图片上传
- 纯文本歌词编辑与展示
- 备注字段
- 歌曲详情页：在线播放、下载、分享

### 3.2 歌曲元数据（2026-07）

| 字段 | 说明 |
|------|------|
| 调 (`key`) | 预设 + 自定义 |
| 拍号 (`timeSignature`) | 预设 + 自定义 |
| 作曲 / 作词 | 自由文本 |
| 团队 | 自由文本（与「团队协作」模块无关） |
| 专辑 | 自由文本 |
| MV | 外链 URL |

### 3.3 聚会记录

- 记录每次聚会的日期、讲员、主领、备注
- 关联本次选用的歌曲（有序）
- 列表按**年份**或**具体月份**（`YYYY-MM`）筛选
- **新建聚会选歌**：搜索曲库（歌名/歌手，不区分大小写）；无结果时可当场手动建歌并加入

### 3.4 排行榜

- 按歌曲在聚会中的**使用次数**完整排名
- 支持「全部时间」或指定**年份**筛选
- 分页：每页 10 / 20 / 50 条

### 3.5 数据导入导出

- Excel 格式批量导入/导出（领队及以上可导入）
- 可按年份导出聚会与歌曲使用数据

### 3.6 分享（基础能力）

- 登录用户可为**单首歌曲**或**聚会**生成公开链接
- 分享页**无需登录**即可查看
- 链接含随机 token（不持久化存储）

### 3.7 用户与权限

| 角色 | 典型能力 |
|------|----------|
| 超级管理员 | 全部权限 + 用户管理 |
| 管理员 | 编辑/上传/删除歌曲与聚会、数据导入导出、歌单管理 |
| 领队 | 编辑/上传歌曲与聚会、创建与管理自己的歌单 |
| 成员 | 浏览、下载、导出 |

登录方式：邮箱密码、手机验证码；支持记住密码。

### 3.8 团队协作

- 创建团队、添加成员、设置团队内角色
- 团队内实时聊天（轮询刷新）
- 新消息提醒

### 3.9 国际化（2026-07）

- 顶栏 / 侧栏 / 登录注册页切换 **EN / 中文**
- 偏好写入 Cookie `locale`，无 URL 语言前缀
- 仅翻译 UI 文案，不翻译曲库内容与 API 错误原文

### 3.10 界面与品牌（2026-07）

- 暖色大地系主题与品牌 Logo
- 响应式布局（桌面 + 移动端侧栏/顶栏）
- shadcn/ui 组件库

## 四、近期新增功能（2026-08）

### 4.1 标签体系 — 取代单一分类

**背景：** 原 `Category` 单选分类无法满足「场合类型 + 风格」的多维标注需求。

**变更：**

- 引入统一 `Tag` 模型，分两类：
  - **TYPE（类型）**：宣教诗歌、主日敬拜、福音布道、圣诞诗歌、复活节诗歌、儿童诗歌、信心回应、敬拜赞美、认罪悔改、迦南诗歌、传统诗歌、英文诗歌
  - **STYLE（风格）**：活泼、忧伤、激励
- 每首歌可多选 TYPE、多选 STYLE
- 歌曲列表支持按标签 **AND** 组合筛选
- 上传/编辑页多选标签；列表卡片展示标签徽章

**相关规格：** [`2026-08-04-playlists-tags-share-design.md`](superpowers/specs/2026-08-04-playlists-tags-share-design.md)

---

### 4.2 歌单（Playlist）

**背景：** 聚会记录面向「已发生的崇拜」；团队还需要独立的「待选/备用歌单」用于排练与分享。

**能力：**

| 操作 | 说明 |
|------|------|
| 创建 | 歌单列表页对话框：名称必填、描述可选；创建后跳转详情 |
| 添加歌曲 | 从歌单详情搜索添加；或从曲库列表/歌曲详情「加入歌单」 |
| 创建并添加 | 「加入歌单」对话框内可新建歌单并立即加入当前歌曲 |
| 排序 / 移除 | 详情页上移/下移、删除单曲 |
| 编辑元数据 | 详情页内联或对话框编辑标题与描述 |
| 权限 | 创建：领队及以上；编辑/删除：创建者或管理员及以上 |

**导航：** 侧栏新增「歌单」→ `/playlists`

**相关规格：**  
[`2026-08-04-playlists-tags-share-design.md`](superpowers/specs/2026-08-04-playlists-tags-share-design.md)  
[`2026-08-04-playlist-create-add-ux-design.md`](superpowers/specs/2026-08-04-playlist-create-add-ux-design.md)

### 4.3 分享增强

**新增分享类型：**

- **歌单分享**（`type=playlist`）：公开页返回歌单元数据 + 按顺序排列的**完整歌曲信息**（歌词、歌谱、音频、元数据、标签、经文等）

**体验增强：**

- 歌谱预览对话框（列表/详情/分享页）
- 歌曲封面图片上传与展示
- 分享页支持歌谱预览

**API：** `POST /api/share` 生成链接；`GET /api/share?type=&id=&token=` 拉取数据

---

### 4.4 歌词能力升级

#### 4.4.1 独立歌词搜索

- 曲库列表保留原有「歌名/歌手」搜索
- 新增**「搜索歌词」**输入框，仅匹配 `lyrics` 字段
- 可与歌名搜索、标签筛选 **AND** 组合

#### 4.4.2 LRC 时间轴歌词

- 歌曲新增可选字段 `lyricsLrc`
- 与纯文本 `lyrics` **独立编辑**，互不同步
- 详情页：有 LRC 时随音频播放高亮/滚动；仅 plain 歌词时静态展示

#### 4.4.3 歌谱 OCR 提取歌词

- 上传歌谱后，可点击「从歌谱提取歌词」
- 使用 **Gemini Vision**（需配置 `GEMINI_API_KEY`）
- 仅返回文本、**不自动写库**；用户确认后填入歌词框
- 若已有歌词，覆盖前需确认

**相关规格：** [`2026-08-04-lyrics-lrc-ocr-search-design.md`](superpowers/specs/2026-08-04-lyrics-lrc-ocr-search-design.md)

### 4.5 经文关联

- 每首歌可关联**多条**经文
- 每条：经文引用（必填，自由文本）+ 经文内容（可选）
- 上传/编辑页动态增删行
- 详情页、分享页展示；列表搜索框可匹配**引用**（不匹配正文）
- 列表卡片可选展示首条引用

**相关规格：** [`2026-08-04-song-scripture-design.md`](superpowers/specs/2026-08-04-song-scripture-design.md)

### 4.7 选歌 AI Agent

**定位：** 全站悬浮对话助手，用自然语言找歌、查热门、加入歌单。

| 项目 | 说明 |
|------|------|
| 入口 | 所有已登录主布局页面右下角 FAB |
| 能力 | 按标签/歌词/歌名推荐、查热门、列出可编辑歌单、将歌曲加入歌单 |
| 技术 | Vercel AI SDK + Tool Calling + Prisma |
| 模型 | 环境变量配置 OpenAI 兼容 API（免费测试推荐 Groq + `llama-3.3-70b-versatile`） |
| 历史 | 保存在浏览器 `localStorage`（按用户 ID） |
| 权限 | 所有登录用户可聊天；加入歌单遵循歌单 ACL（成员会被明确拒绝） |
| 未配置 | 无 `AI_API_KEY` 时接口返回 503，界面提示不可用 |

**Agent 工具一览：**

| 工具 | 作用 |
|------|------|
| `searchSongs` | 歌名/歌手/歌词模糊搜索，可选标签 AND 过滤 |
| `listTags` | 列出 TYPE / STYLE 标签 |
| `getPopularSongs` | 按聚会使用次数的热门歌曲 |
| `listMyPlaylists` | 当前用户可修改的歌单 |
| `addSongToPlaylist` | 将指定歌曲加入歌单 |

**相关规格：** [`2026-08-04-song-selection-agent-design.md`](superpowers/specs/2026-08-04-song-selection-agent-design.md)

## 五、模块关系图

```
                    ┌─────────────┐
                    │   仪表盘     │
                    └──────┬──────┘
                           │
     ┌─────────────────────┼─────────────────────┐
     │                     │                     │
┌────▼────┐          ┌─────▼─────┐         ┌─────▼─────┐
│  曲库    │◄────────►│   歌单     │         │   聚会     │
│ Songs   │  加入歌单  │ Playlists │         │ Meetings  │
└────┬────┘          └─────┬─────┘         └─────┬─────┘
     │                     │                     │
     │    标签/经文/歌词     │                     │
     └──────────┬──────────┘                     │
                │                                │
         ┌──────▼──────┐                  ┌──────▼──────┐
         │    分享      │                  │   排行榜     │
         │ Share 页    │                  │ Leaderboard │
         └─────────────┘                  └─────────────┘
                ▲
                │ 选歌 Agent 可搜索并写入歌单
         ┌──────┴──────┐
         │ 选歌 Agent   │
         └─────────────┘

┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐
│  团队    │  │  数据    │  │ 用户管理 │  │  设置    │
│ Teams   │  │  Data   │  │ Admin   │  │Settings │
└─────────┘  └─────────┘  └─────────┘  └─────────┘
```

**数据流要点：**

- **聚会**记录「实际用过哪些歌」→ 驱动**排行榜**
- **歌单**是独立编排，不影响聚会统计
- **标签**同时服务于曲库筛选、歌单加歌搜索、Agent 推荐
- **分享**统一出口：歌曲 / 聚会 / 歌单
