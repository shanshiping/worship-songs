## 1. 登录与账户

**路由：** `/login`、`/register`

### 登录方式

| 方式 | 步骤 |
|------|------|
| 邮箱登录 | 输入注册邮箱与密码 → 登录 |
| 手机验证码 | 输入手机号 → 获取验证码 → 登录 |
| 记住密码 | 勾选后下次自动填充（浏览器本地） |

### 注册

使用邮箱注册新账户。默认角色为**成员**；管理员可在后台调整角色。

### 常见问题

- **登出后未回到登录页：** 已修复，登出会可靠跳转至登录页。
- **无编辑按钮：** 检查账户角色是否为领队及以上。

## 3. 曲库（歌曲）

**路由：** `/songs`、`/songs/upload`、`/songs/[id]`、`/songs/[id]/edit`  
**权限：** 查看：全员；上传/编辑：领队及以上；删除：管理员及以上

### 3.1 歌曲列表 `/songs`

| 功能 | 操作说明 |
|------|----------|
| 搜索歌名/歌手 | 顶部搜索框，不区分大小写 |
| 搜索歌词 | 独立「搜索歌词」框，只在歌词正文中匹配 |
| 标签筛选 | 筛选栏多选 TYPE（类型）与 STYLE（风格）；多个标签为 AND 关系 |
| 点击标签徽章 | 在卡片上点击 TYPE/STYLE 徽章可快速切换筛选；点「未分类」清除标签筛选 |
| 加入歌单 | 行内「加入歌单」→ 选择已有歌单或新建后添加 |
| 上传歌曲 | 领队及以上可见「上传」按钮 |

### 3.2 上传歌曲 `/songs/upload`

**必填：** 歌名  
**可选字段：**

| 分类 | 字段 |
|------|------|
| 基本信息 | 歌手、备注 |
| 元数据 | 调、拍号、作曲、作词、团队（文本）、专辑、MV 链接 |
| 媒体 | 封面图、歌谱、音频 |
| 歌词 | 纯文本歌词、LRC 时间轴歌词 |
| 标签 | TYPE / STYLE 多选 |
| 经文 | 多条：引用 + 可选正文 |

**歌谱 OCR 提取歌词：**

1. 先上传歌谱文件  
2. 点击「从歌谱提取歌词」  
3. 等待识别（需服务器配置 Gemini API）  
4. 结果填入歌词框；若已有内容会提示是否覆盖  

**LRC 格式示例：** `[00:12.00]第一句歌词`

### 3.3 歌曲详情 `/songs/[id]`

| 功能 | 说明 |
|------|------|
| 播放音频 | 内置播放器 |
| LRC 跟唱 | 有 LRC 时随播放进度高亮；仅 plain 歌词时静态显示 |
| 歌谱预览 | 点击歌谱可弹窗预览（图片/PDF） |
| 下载 | 下载歌谱或音频（按权限） |
| 分享 | 生成公开链接 |
| 编辑标签 | 有编辑权限时，点击封面区域 → 对话框快速改标签 |
| 加入歌单 | 将本曲加入你拥有或可编辑的歌单 |
| 编辑/删除 | 跳转编辑页或删除（按权限） |

### 3.4 编辑歌曲 `/songs/[id]/edit`

与上传页字段一致。保存后返回详情页。

### 3.5 标签说明

**TYPE（类型）示例：** 主日敬拜、圣诞诗歌、儿童诗歌、敬拜赞美……  
**STYLE（风格）示例：** 活泼、忧伤、激励  

一首歌可同时拥有多个类型和多个风格标签。

### 3.6 经文

- 在上传/编辑页「关联经文」区域添加
- 引用必填（如「约翰福音 3:16」），正文可选
- 列表搜索框也会匹配经文**引用**（不匹配正文）

## 4. 歌单

**路由：** `/playlists`、`/playlists/[id]`  
**权限：** 查看：全员；创建/编辑自己的歌单：领队及以上；编辑他人歌单：管理员及以上

### 4.1 歌单 vs 聚会

| | 歌单 | 聚会 |
|---|------|------|
| 用途 | 排练清单、主题合集、对外分享 | 记录某次崇拜实际使用的歌曲 |
| 是否影响排行榜 | 否 | 是 |
| 典型场景 | 「复活节预备歌单」 | 「2026-03-15 主日崇拜」 |

### 4.2 创建歌单

1. 进入 `/playlists`  
2. 点击「新建」  
3. 填写名称（必填）、描述（可选）  
4. 创建后自动进入歌单详情  

### 4.3 歌单详情 `/playlists/[id]`

| 操作 | 说明 |
|------|------|
| 添加歌曲 | 「添加歌曲」→ 搜索 + 标签筛选 → 点击添加 |
| 排序 | 上移 / 下移按钮调整顺序 |
| 移除 | 从歌单删除某首（不删曲库中的歌） |
| 编辑信息 | 修改标题、描述 |
| 分享 | 生成歌单公开链接（含完整歌曲信息） |
| 删除歌单 | 创建者或管理员 |

### 4.4 从曲库加入歌单

在**歌曲列表**或**歌曲详情**点击「加入歌单」：

1. 选择目标歌单  
2. 或点击「新建歌单」→ 创建后立即加入当前歌曲  

### 4.5 权限说明

- **成员：** 可浏览所有歌单，不能创建或修改  
- **领队：** 可创建歌单；只能编辑/删除**自己创建**的歌单  
- **管理员 / 超管：** 可编辑/删除任意歌单

## 5. 聚会

**路由：** `/meetings`、`/meetings/new`、`/meetings/[id]`  
**权限：** 查看：全员；创建/编辑：领队及以上；删除：管理员及以上

### 5.1 聚会列表 `/meetings`

- 按**年份**下拉筛选（仅有数据的年份）  
- 按**月份**筛选（格式 `YYYY-MM`）  
- 点击进入详情  

### 5.2 新建聚会 `/meetings/new`

1. 填写日期、讲员、主领、备注  
2. **选歌：** 搜索歌名/歌手（不区分大小写）  
3. 从结果中点选加入列表  
4. **搜不到时：** 可手动填写歌名、歌手、标签，当场创建新歌曲并加入  
5. 提交保存  

### 5.3 聚会详情 `/meetings/[id]`

- 查看本次歌曲顺序与元信息  
- 分享本次聚会歌单（公开页）  
- 编辑 / 删除（按权限）  

### 5.4 与排行榜的关系

每次聚会保存的歌曲会计入该曲的**使用次数**，供排行榜统计。

## 6. 排行榜

**路由：** `/leaderboard`  
**权限：** 所有登录用户

### 功能

| 选项 | 说明 |
|------|------|
| 年份 | 「全部时间」或选择某一历年 |
| 排序 | 按聚会使用次数降序 |
| 分页 | 每页 10 / 20 / 50 条 |

### 使用场景

- 了解团队常选歌曲  
- 年度回顾、选歌参考  
- 选歌 Agent 的「热门歌曲」与此数据源一致

## 7. 分享

**路由：** `/share/[type]/[id]?token=...`（公开，无需登录）  
**生成入口：** 歌曲详情、聚会详情、歌单详情上的「分享」按钮

### 分享类型

| type | 内容 |
|------|------|
| `song` | 单首：歌词、歌谱、音频、元数据、标签、经文、最近聚会记录 |
| `meeting` | 聚会信息 + 有序歌曲列表（含每首完整信息） |
| `playlist` | 歌单信息 + 有序歌曲列表（含每首完整信息） |

### 使用步骤

1. 在详情页点击「分享」  
2. 复制生成的链接发给弟兄姊妹  
3. 对方打开链接即可查看（无需账号）  

### 说明

- 分享页显示**纯文本歌词**（无 LRC 跟唱，因公开页无播放器同步）  
- 支持歌谱预览  
- Token 为一次性随机串，不存入数据库；链接长期有效取决于 id 是否仍存在

## 8. 选歌 AI Agent

**入口：** 登录后任意主页面右下角的**对话浮动按钮**  
**权限：** 聊天：全员；加入歌单：领队及以上（且需对该歌单有编辑权）

### 能做什么

用自然语言提问，例如：

- 「找几首复活节、活泼的敬拜歌」  
- 「歌词里有『恩典』的歌有哪些？」  
- 「最近大家常选的前五首是什么？」  
- 「把《Amazing Grace》加到我的主日歌单」  

### Agent 工作方式

1. 理解你的描述  
2. 调用内部工具搜索曲库、查标签、查热门、列出歌单  
3. 仅推荐**工具返回的真实歌曲**，不会编造不存在的歌  
4. 可将歌曲加入你有权限的歌单  

### 对话历史

- 保存在本浏览器 `localStorage`（按用户区分）  
- 换设备或清缓存会丢失  
- 界面提供清除历史按钮  

### 配置要求

服务器需配置 `AI_API_KEY` 等环境变量。未配置时按钮可能仍在，但发送消息会提示服务不可用。

**免费测试推荐：** Groq + `llama-3.3-70b-versatile`（见 `.env.example`）

### 当前不支持

- 按旋律/音频找歌  
- 服务端永久保存聊天记录  
- 成员账户通过 Agent 修改歌单（会收到明确拒绝说明）

## 9. 数据导入导出

**路由：** `/data`  
**权限：** 导入：领队及以上；导出：全员

### 导入

- 上传 Excel 批量写入曲库/聚会数据  
- 适合初次迁移历史表格  

### 导出

- 按年份导出 Excel  
- 成员也可导出供本地备份  

### 注意

- 导入/导出**暂未包含**全部新字段（如标签、经文、LRC）；以界面手动维护为准  
- 大批量操作建议由领队或管理员执行

## 10. 团队与聊天

**路由：** `/teams`、`/teams/[id]`、`/teams/[id]/settings`  
**权限：** 所有登录用户可参与已加入的团队

### 创建团队

1. `/teams` → 「创建团队」  
2. 填写名称、描述  

### 添加成员

团队设置页输入成员**邮箱**邀请加入。

### 在线聊天

进入团队页即可发送文字消息；页面定时刷新显示新消息。

### 与歌曲「团队」字段的区别

| | 协作「团队」模块 | 歌曲元数据「团队」 |
|---|------------------|-------------------|
| 性质 | 平台内用户组 + 聊天 | 自由文本（如「某某诗班」） |
| 是否关联 | 否 | 否 |

## 12. 语言切换

**位置：** 顶栏或侧栏的 **EN / 中文** 切换

| 项目 | 说明 |
|------|------|
| 默认语言 | 英文 (`en`) |
| 持久化 | Cookie `locale` |
